# Portafolio de fotografía — Marcela Hoyos

Sitio estático (HTML + CSS + JS, sin dependencias). Abre `index.html` en el navegador para verlo.

- **Fotos:** van en `images/`. La lista de nombres está en [`images/README.md`](images/README.md).
- **Textos:** se editan directamente en `index.html`.
- **Colores y tipografías:** al inicio de `css/styles.css` (`:root`).
- **Video:** pega el enlace *embed* de YouTube/Vimeo en `data-src` de `.video__frame` en `index.html`.

Para publicarlo gratis puedes activar **GitHub Pages** (Settings → Pages → rama `main`, carpeta `/root`).
